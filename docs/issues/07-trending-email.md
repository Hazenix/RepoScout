# 07: Trending 每日邮件

**What to build:** 使用本机安全保存的 QQ 邮箱发件授权，在当天扫描结束后把首次推送的 Trending 仓库摘要发到用户配置的同一邮箱。邮件在北京时间 18:00 之前不发；无新仓库时不发空邮件。

**Blocked by:** 02 Trending 仓库推荐与取舍；06 开机补跑与每日幂等。

**Status:** ready-for-agent

- [ ] 发件账号与收件地址由配置提供；SMTP 授权码保存在 macOS 凭据存储，不出现在代码、日志、报告或提交中。
- [ ] 邮件包含首次推送的仓库、简短说明和 GitHub 链接；已关注、已忽略或成功推送过的仓库不再重复发送。
- [ ] 18:00 前扫描完成时等到 18:00 发；18:00 后才完成或开机补跑时，在结果就绪后发一次。
- [ ] 只有确认投递成功后才记录“已推送”；失败可重试且不制造重复邮件。实际向配置的收件箱发送测试邮件并核对收件结果。
