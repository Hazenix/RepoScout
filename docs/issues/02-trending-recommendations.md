# 02: Trending 仓库推荐与取舍

**What to build:** 在看板展示 GitHub 全语言今日 Trending 中尚未处理的仓库，供用户关注、标记“不感兴趣”和撤销选择。推荐保持 Trending 顺序，最多展示十个；已关注、已推送或已忽略的仓库不再出现在新推荐中。

**Blocked by:** 01 本机看板与关注仓库。

**Status:** ready-for-agent

- [ ] 可获取今日全语言 Trending；获取失败时看板显示失败，既不把旧榜单冒充今日榜单，也不删除既有选择。
- [ ] 排除已关注、已推送和已忽略仓库后，按原榜单顺序展示最多十个；同一仓库不会因连续上榜而成为新的待推送项。
- [ ] 点击关注后进入已关注列表并退出待决定列表；点击“不感兴趣”后不再推荐；撤销后恢复可推荐资格。
- [ ] 刷新页面和重启应用后上述选择保持一致；推荐行为不依赖个性化评分。
