**Blocked by:** 05 每日审查全部已关注仓库。

**Status:** ready-for-agent

- [ ] 关机错过 13:00 后首次开机执行一轮最新扫描，而不是逐日补发多轮旧扫描。
- [ ] 睡眠唤醒、重复启动应用或定时器重试不会让同一日同一仓库产生并行或重复的完整审查。
