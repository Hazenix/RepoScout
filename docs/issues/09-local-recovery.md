# 09: 本机数据备份与恢复

**What to build:** 备份并恢复本机看板的关注选择、忽略记录、报告、机会历史和邮件投递记录。恢复后看板保持原样，下一次扫描不会把旧机会或旧仓库重新当作新内容发邮件。

**Blocked by:** 08 新 PR 机会合并到每日邮件。

**Status:** ready-for-agent

- [ ] 可生成并验证可读取的本机数据备份；备份不包含 QQ SMTP 授权码或 GitHub 凭据。
- [ ] 在隔离环境中恢复备份后，三个看板视图、关注/忽略选择和历史报告与备份前一致。
- [ ] 恢复后的首次完整扫描不重发以前已成功推送的仓库或机会。
- [ ] 备份或恢复失败时保留原有数据，并显示可用于排查的错误，不声称恢复成功。
