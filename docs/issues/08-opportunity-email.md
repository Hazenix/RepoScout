# 08: 新 PR 机会合并到每日邮件

**What to build:** 在同一封日报中，按仓库列出本次完整 `pr-hint` 审查首次发现的新机会。重复机会与旧报告不重发；某库失败时仍可发送 Trending 和其他已完成库的新内容。看板继续保留完整报告。

**Blocked by:** 04 机会历史、旧报告导入与去重；07 Trending 每日邮件。

**Status:** ready-for-agent

- [ ] 每仓库最多使用 `pr-hint` 主推荐的四项；邮件列出当天所有首次发现的推荐，不做跨仓库评分或全局前四。
- [ ] 一封邮件按“新仓库”“新 PR 机会”分区；每项含可独立阅读的简短理由和 GitHub 链接，完整报告留在看板。
- [ ] 已导入的旧机会、重复机会、已忽略机会及失败库未经核验的发现不进入邮件；既无新仓库也无新机会时不发。
- [ ] 一个仓库失败时，其余已完成仓库与 Trending 的新内容照常发送；关闭、认领、评论等后续变化不触发机会邮件。
- [ ] 对同一天的重复执行和 SMTP 重试做端到端核对，收件箱不会出现重复日报。
