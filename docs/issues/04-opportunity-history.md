# 04: 机会历史、旧报告导入与去重

**What to build:** 把四个初始关注仓库的现有报告显示为带原始日期的历史记录，并让同一机会在后续完整调研中保留同一张卡片。旧结论先待复核；用户能忽略机会，系统只在有明确证据时标为失效。

**Blocked by:** 03 单仓库 pr-hint 调研与报告展示。

**Status:** ready-for-agent

- [ ] 四库旧报告导入后显示原调研日期与“待复核”，不直接标为当前有效，也不算作首次发现的新机会。
- [ ] 同一机会在重复报告中只保留一张可追溯历史的卡片；重新运行不产生重复卡片。
- [ ] 看板能区分当前有效、已失效和已忽略；仅从本轮前四项消失不自动等于失效。
- [ ] 忽略的机会仍保留历史，但不再作为新机会推送；完整报告和 GitHub 证据链接可打开。
