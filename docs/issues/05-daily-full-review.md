# 05: 每日审查全部已关注仓库

**What to build:** 每天北京时间 13:00 对当时全部已关注仓库逐一运行完整 `pr-hint` 调研，并在看板展示各库本轮结果。一个仓库失败不阻断其他仓库；不能完成的工作明确留下未完成状态。

**Blocked by:** 03 单仓库 pr-hint 调研与报告展示。

**Status:** ready-for-agent

- [ ] 每个已关注仓库每天进入完整调研，不用变更预筛、轮转、抽样或静默降频代替。
- [ ] 新关注仓库进入后续每日调研；已取消关注仓库不再进入调研。
- [ ] 看板区分运行中、完成且无机会、完成且有机会、失败或未完成；单库失败后其他库继续。
- [ ] 关注数过多导致当天无法结束时，如实展示未完成，不能把尚未核验的内容标为机会。
