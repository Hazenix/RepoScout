# PR 监控

打开 macOS 应用侧栏的「PR 监控」，查看自己发起的 PR 总数、各仓库的分布，以及 Open、Merged、Closed 状态。列表中的链接可直接打开 GitHub PR。

## 统计范围

数据来自 `gh` 当前登录的 GitHub 账号，覆盖该账号历年发起、且当前授权能够读取的 PR，包括有权访问的私有仓库。面板显示账号与最近一次成功同步时间，数字以这次完整快照为准。

- **Open**：仍打开的 PR，包含 Draft。
- **Merged**：已经合并的 PR。
- **Closed**：关闭且未合并的 PR。

三种状态互斥，相加为 PR 总数；Draft 是 Open 的子集，不额外计入总数。无法访问的仓库不在统计范围内。

## 查看分布与列表

仓库分布按 PR 数量排序，以不同颜色堆叠展示三种状态；展开可查看全部仓库。可按状态、仓库筛选列表，也可搜索仓库或 PR 标题。列表展示 PR 状态并提供 GitHub 链接。

## 同步与离线读取

本机后台服务启动后会同步，之后每 15 分钟自动更新；也可在面板手动同步。应用优先读取已保存的完整快照，因此打开面板无需等待 GitHub 请求。断网时仍可通过运行中的本机服务查看缓存，同步需要网络。

首次同步尚未完成时，面板显示等待状态。同步失败时保留上次成功的完整结果、时间和错误信息；未取全的数据不会替换缓存，也不会显示为零个 PR。

## 更换账号

先在终端核对或切换 GitHub CLI 的当前账号：

```sh
gh auth status
gh auth switch --hostname github.com --user YOUR_GITHUB_LOGIN
```

随后在 PR 监控面板手动同步，并核对面板中的账号。新账号完整同步成功后显示它的结果；同步期间看到的旧快照仍属于面板标明的账号。

PR 监控只读取 GitHub 数据并保存本机缓存，不修改 PR、仓库或 GitHub 关注状态，也不触发邮件。
